# 🐍 Python String Practice

This repository contains my **Python string practice programs**, covering basic to intermediate string manipulation and problem-solving concepts.

The purpose of these exercises is to improve my understanding of **loops, conditions, strings, functions, dictionaries, ASCII values, and built-in string methods**.

## 📚 Topics Covered

### 🔄 String Reversal & Palindrome

* Reverse a string without using slicing.
* Check whether a string is a palindrome.

### 🔤 Character Counting

* Count vowels in a string.
* Count consonants in a string.
* Count digits in a string.
* Count spaces in a string.
* Count words in a string.
* Find the frequency of every character.
* Find duplicate characters.
* Find the first non-repeating character.

### 📏 String Length

* Find the length of a string without using `len()`.

### 🔠 Case Conversion

* Convert lowercase characters to uppercase without using `.upper()`.

### ✂️ String Manipulation

* Remove spaces from a string.
* Replace vowels with `*`.
* Capitalize every word.

### 🔎 Searching & Validation

* Check whether a string contains only digits.
* Check whether a string contains only alphabets.
* Extract numbers from a string.
* Extract email addresses from a string.

### 📝 Word Operations

* Find the longest word in a sentence.
* Find the shortest word in a sentence.
